# Member navigation at enlarged text

Status: frozen presentation clarification of shared primitive 4 and the
existing CLS-Q9/PTF-Q9 standing conditions, 2026-10-03. No routes, labels,
identity classifications or grants change.

Home, Classes, Shop, Activity and You remain five individually visible primary
destinations. At the contracted narrow viewport and actual 200-percent text,
each full visible label must fit its own interactive destination without
clipping or painting over another label. Wrapping and a taller navigation area
are acceptable; shrinking the requested text, hiding words, ellipsizing labels
or suppressing a destination does not meet the existing bar.

The fixed navigation must also leave the last meaningful page content/action
reachable above it when the page is scrolled to the end. Preserve the existing
44-pixel web target requirement, one current destination, themes, keyboard
semantics and BIZ vocabulary. Framework development overlays are not app controls.

Independent visible browser tests enlarge actual computed text sizes, then use
the public navigation links and rendered text bounds to detect label collisions
or clipping. They verify the last meaningful main content at the scroll end.
Their observed failures precede the separate central presentation integrator.
This remains bounded web evidence; Android layout is verified at final runtime.
