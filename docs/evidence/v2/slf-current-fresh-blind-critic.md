## Major findings

1. **Authenticated private finish bypasses the required command gates.** Lines 770–978 and authenticated grant 1647–1648: `app.slf_freeze_finish` independently validates the staff and target but never takes the member serialization lock, checks a revision/replay, checks effectiveness or runs overlap/allowance validation. Most directly, calling its `expire` branch on a future effective open request closes it and audits expiry (947–974), while the public preparation would refuse that same action (668–671). Direct adoption also accepts an existing matching pending source without checking reason equality (818–825), freshness, overlap or eligibility. The private schema's lack of PostgREST exposure is not a substitute for the explicitly required direct-call defense. Violates SLF-006/010/013 and the frozen private-helper boundary: “a direct call must grant nothing extra.”

2. **Direct source decisions can leave permanent contradictory request truth, and ineffective requests can still be approved directly.** Lines 347–388 enforce only membership/dates and cancelled/expired persisted status. A direct ordinary configured-role staff update can approve a linked `desk_submitted` source, including an effectively expired one, and commit while the request stays `desk_submitted`. No deferred consistency trigger exists. The ordinary pause guard does not enforce this feature's request agreement/effectiveness. Cancellation can subsequently close the still-open request after the source has already been approved; cancellation does not inspect or lock that source (1177–1225). Violates SLF-009/010/014 and the frozen requirement for immediate ineffective-source refusal plus transaction-completion agreement.

3. **Closed or ineffective linked pending history wrongly reserves days.** Source-overlap predicates at 699–708 and 1119–1125 count every non-rejected source, including undecided source rows linked to cancelled/expired SLF requests. Those rows are deliberately retained on withdrawal/expiry and must cease reserving dates. Adoption/approval's other-request predicate (694–695) also tests `ends_on >= today` instead of the shared effectiveness predicate, so elapsed-start or unavailable-target open rows may block an otherwise eligible interval. Violates SLF-005/010. The own adopted pending pause is correctly excluded by line 705; removing all pending sources would weaken protection for real competing desk pauses and would not be an acceptable repair.

4. **Staff authority omits eligible-gym validation.** `app.slf_front_office_staff` ends after current staff binding/active/role validation (478–499); unlike the member validator (458–461), it never checks that the organization is active. All staff reads, replay and commands consequently admit an otherwise matching active employee of an ineligible gym. Violates SLF-003's eligible-gym revalidation before target/replay.

5. **Commercial evidence is not locked/revalidated for the full transaction.** Preparation locks only the SLF request (623–626). It does not lock the membership, member, source pause or settings; `slf_freeze_ineffective` omits current membership starts-on and interval containment (526–534), and adoption performs no further span validation. A membership can be shortened after request creation, then the old interval adopted/approved outside the current span. Ordinary source writers take no SLF resource lock, so a competing desk source can be inserted/approved between the overlap/allowance read and final source write. This is distinct from the accepted OPEN-016 general allowance residual: SLF-006/007/012 explicitly require its own final locked revalidation of target/current evidence. Violates SLF-005/006/007/012 and the public lock-boundary contract.

6. **Exact desk replay reports a non-replay and omits current effective state.** Preparation detects an exact replay and wraps the immutable stored result (635–639), but each desk wrapper returns that inner result unchanged (1269–1270, 1311–1312, 1387–1388, 1429–1430). Every stored result has `replayed=false`. The callers therefore receive false for actual replay, and no current effective state is added; member create/cancel replay sets true but likewise omits current effective state (1032–1036, 1204–1208). Violates SLF-013 and the frozen return boundary.

7. **Every-writer terminal/link invariants are incomplete.** Terminal-row guard at 278–280 prohibits only status changes; an expired terminal row with no prior decision can acquire a decision pair/reason with revision increment under 284–297. The frozen rule permits only `updated_at` on any terminal row. The source guard never checks tenant, reason or requester agreement (368–370), and there is no request-side insert/link trigger proving membership/member relationship and source agreement for privileged writers. Composite FKs prove tenant membership, not that the membership belongs to the named member. Violates SLF-014 and the frozen exact-link/every-writer boundary.
